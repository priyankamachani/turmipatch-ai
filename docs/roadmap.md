# TurmiPatch AI Roadmap

## Phase 1: Foundation

- Create GitHub repository
- Add project README
- Document the concept
- Add product vision
- Collect wound-care research
- Build public project presence

## Phase 2: Research

- Review wound healing challenges
- Research turmeric and curcumin in wound care
- Study AI applications in healthcare monitoring
- Understand medical device and digital health regulations

## Phase 3: Prototype Planning

- Define sample wound healing data points
- Design AI monitoring logic
- Create sample datasets
- Build a simple healing progress prediction model

## Phase 4: Product Vision

- Design smart patch user journey
- Create wireframes for patient and clinician dashboards
- Explore sensor integration possibilities
- Prepare future pilot and research collaboration plan

## Phase 5: Scale-Up Vision

- Explore UK health-tech partnerships
- Investigate NHS innovation pathways
- Build evidence for clinical validation
- Develop a responsible AI and healthcare safety framework
