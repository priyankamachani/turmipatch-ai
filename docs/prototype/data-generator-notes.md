# Synthetic Data Generator Notes

## Overview

The synthetic data generator creates sample wound-healing records for TurmiPatch AI prototype testing.

The purpose is to support early AI experimentation without using real patient data.

## Generated Dataset

The script creates:

- 50 synthetic patients
- 6 monitoring days per patient
- 300 total wound monitoring records

The generated data is saved to:

```text
prototype/sample-data/generated-wound-data.csv
