# TurmiPatch AI Model Plan

## Overview

This document explains the early AI testing approach for TurmiPatch AI.

The current prototype uses synthetic wound-healing data to explore how wound-related indicators could be combined into a basic healing risk score. This is not a clinical model. It is an early concept-development prototype designed to support future AI experimentation.
